# Explainability is Encodability

**A sheaf-theoretic foundation for neural network interpretability, formalized in Lean 4.**

> 可解释性 = 可编码性：神经网络可解释性的层论基础

---

## The claim

A network is *interpretable* iff its layer family can be generated by a single source object
along the layer ladder. This turns "black box" into a positive proposition:

> **A black box is a network with no code.** Not that we fail to understand it — that no source
> generates it.

Formally: coherent network states and single-layer objects are related by a pair of mutually
inverse maps, and the encoding is injective.

```lean
theorem interpretability_is_encodability (L : LayerLadder) (hm : 0 < L.m) (n : ℕ) :
    (∀ f : NetState L n, Coherent L n f ↔ ∃ g, f = encode L hm g) ∧
    (∀ g, Coherent L n (encode L hm g)) ∧
    Function.Injective (encode L hm (n := n)) ∧
    (∀ g, decode L hm (encode L hm g) = g) ∧
    (∀ f, Coherent L n f → encode L hm (decode L hm f) = f)
```

## Four results

| # | Result | Where |
| --- | --- | --- |
| 1 | **Interpretable ⟺ encodable** — inverse pair, injective encoding | §5 |
| 2 | **The cost is a number** — `gap = (c/a + 1)²` for ReLU; `√gap(g∘f) = √gap(f) + (√gap(g)−1)/a₁` | §6 |
| 3 | **Interpretability and generalization point opposite ways** — capacity `N < 2B/√g + 1`; black boxes are *not supposed to be repaired* | §7 |
| 4 | **`b₁` is a function of the site, not of the network** — on the observation ladder it is identically 0 | §8 |

The third is the counterintuitive one: the gap is also the reciprocal of capacity, so a larger gap
means easier generalization *and* worse interpretability. **The black box cannot be repaired
(information is already lost) and should not be (repairing it destroys generalization).**

## Why ℚ and why constructive

The choice of ℚ is not a technical convenience — it is part of the content:

- **Symbols must be writable.** Every element of ℚ is a pair of finite integers; almost no real
  is. §2.5 turns this into a theorem (continued-fraction encoding).
- **The hole must be countable.** `entropy f = 2^|α| − |image f|` only makes sense finitely.
- **Refusing the continuum is refusing infinite divisibility.** Every division leaves a remainder,
  so there is no infinite descending chain of positive integers.

Consequently the paper does not claim: generalization error bounds (needs measure), "almost all"
(needs measure or choice), or "the supremum exists" (needs completeness — which is exactly why
`gap` is stated as a **relation** `IsGap`, not a function).
